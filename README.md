# Solar Wind Mission Control Dashboard

A Streamlit dashboard for exploring and analysing solar wind data (Python mini project).

## Files
- `app.py` – the main Streamlit dashboard
- `run_dashboard.py` – launcher script
- `requirements.txt` – Python dependencies
- `dataset on solarwind.zip` – the dataset (unzip before running)
- `SolarWind_FDS_Dashboard_...zip` – exported HTML version of the dashboard

## How to run
1. Unzip `dataset on solarwind.zip` into this same folder.
2. Install dependencies: `pip install -r requirements.txt`
3. Start the dashboard: `python run_dashboard.py`
